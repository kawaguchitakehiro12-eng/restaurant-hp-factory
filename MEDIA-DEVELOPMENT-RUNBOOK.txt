IMPLEMENTED
- ImageWorkflow validates/decompresses/re-encodes PNG/JPEG/WebP with sharp, strips metadata,
  fits photos inside 1440px and logos inside 512px, WebP quality 78, output <=500KB.
- 50,000,000-byte per-store quota includes reserved/review/retired objects. Concurrent
  updates use metadata CAS, no automatic replay on unknown acknowledgements.
- R2 conditional create, readback/hash verification; immutable random keys.
- Durable Supabase metadata adapter and NEW media-assets-v1.sql proposal (not applied).
- HMAC body/path/time-bound app -> Worker control; separate preview signature secret.
- Worker reads private R2; no Supabase query per image. Authorize before byte cache.
- HTTP responses no-store; internal byte cache long-lived. Disable all outer Worker
  response caching / Workers Caching / Cache Everything rules on this route.
- Per-site policy cached <=30s; demo expiry and contractEnds evaluated on every request.
- Global lease cached <=30s, valid <=60s. Any unknown sync blocks lease renewal.
- Batch sync changes only changed/expiring policy records, NOT all stores every 30s.
  Source must exhaust pagination, include stopped/deleted stores as tombstones, and
  confirm complete=true only after all authoritative queries succeed.
- Customer upload endpoint, logo/photo/menu/gallery editor context, save-time conversion,
  canonical reference validation and ownership checking. Existing mode stays default.
- Migration coordinator prepares copies, preserves source, verifies objects, stages
  publication before content CAS; no physical cleanup on failure.
- Retire is logical only. No delete endpoint or automatic old-object garbage collection.
